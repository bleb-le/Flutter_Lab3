## Запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/bleb-le/Flutter_Lab3
   ```
2. Перейти в папку проекта:
   ```bash
   cd first_flutter_app
   ```
3. Выполнить `flutter pub get`
4. Запустить командой `flutter run -d chrome`
